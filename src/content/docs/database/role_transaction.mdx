# `pnerp.role_transaction`


**Bezbjednost** — Dodjela transakcija ulogama


## Opis

Veza više-prema-više koja dodjeljuje transakcije ulogama.

## Kolone

| Naziv kolone | Tip podatka | Nullable | Default | Napomena |
| :--- | :--- | :---: | :---: | :--- |
| RoleID | smallint | NE |  | 🔗 SV → `role`; kompozitni PK |
| TransactionID | smallint | NE |  | 🔗 SV → `transaction`; kompozitni PK |

## Indeksi

Kompozitni PK. Indeks na TransactionID.

## Relacije

SV → role, transaction.
